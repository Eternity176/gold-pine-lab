What this is

Gold Pine Lab is a standalone, TradingView-like web app for testing Pine Script indicators and strategies on real XAUUSD M1 candles (2023–2025, Dukascopy BID, 1,008,574 bars). No account, no TradingView, no MT5 needed. Pick a symbol/timeframe and press Run — candles load automatically from the bundled data. CSV upload is an optional fallback for other symbols.

Tester conventions (mandatory, match the lab)

  • Commission $0.11/oz round-trip = $0.055 per side — set in your strategy as commission_type=strategy.commission.cash_per_contract, commission_value=0.055. Slippage 0.
  • Gap-fill exits: if a bar opens beyond your SL/TP, the exit fills at the open — never credited at the level. Verified synthetically on PineTS (see README).
  • No trailing stop in R7 strategies. SL is fixed at entry.
  • Market orders fill at the next bar open. Only closed bars are used for signals.
  • Margin: PineTS rejects orders whose 1% margin exceeds equity. R7 sets margin_long=1, margin_short=1 so a 1 oz order needs ~$26 margin at $2,600 gold. Without it, large qty on small capital fills 0 trades.
  • 8 gates (all must pass in BOTH IS 2023–24 and OS 2025): monthly ≥ 20%, max equity DD ≤ 10%, realized R:R ≥ 1.5, ≥ 1 trade/day, PF ≥ 1.5, expectancy > 0, no month < −10%, sample ≥ 240 trades/period. OS equity is rebased to $10k at the 2025-01-01 split.
  • Realized R:R is reported as the payoff ratio avgWin/|avgLoss| — exact when risk/trade is constant.

Live data (● Live data button, top bar)

Live candles are real XAUUSD, NOT PAXG. PAXG was removed 2026-11-10: measured that day, PAXG traded $13–20 BELOW spot — unusable for M1 gold work. Primary source is Dukascopy XAU/USD BID (true spot), the same source as the bundled history, served through this site's own /api/live proxy (Vercel server function, no key). Fallback is Yahoo GC=F (COMEX gold futures) — real gold, but futures trade a few dollars above spot (basis varies, jumps at contract roll) and halt daily, so bars can be missing around the halt; the spot chip always shows true spot. The spot XAU price chip in the top bar comes from gold-api.com (spot only — it has no candles). Live appends the latest ~1,000 1m bars to the bundled data (merge by minute, no duplicates, no chart reset); the current Pine result stays on the chart. Live is ON by default — it starts itself when the page loads and refreshes every 5s, so the price runs realtime with no button press and no waiting; press ● Live ON again to stop it. When a new minute bar arrives and the script is unchanged, the Pine preview re-runs by itself so the Pine pane follows live bars (Tester full-history numbers are never replaced by that re-run).

Feed chain, tried in order (8s timeout each; first source returning ≥ 1 row wins): /api/live → Dukascopy XAU/USD BID (spot) → Yahoo GC=F (futures), then direct Dukascopy json3 JSONP from the browser as a last resort. If all fail, the status bar lists every attempt with its reason (HTTP status / timeout) instead of a generic "Failed to fetch" — and the bundled data stays on screen. No public CORS proxy is used. Note: there is a gap between the bundled end (2025-11-04) and the live window — live bars are appended, not backfilled.

Data

Default: bundled data/2023–2025 (20.17 MB total; 352,949 + 355,787 + 299,838 bars = 1,008,574), shipped as base64 chunks (data/manifest.json + data/*.b64.N) with the original .bin files as a local-dev fallback, cached in IndexedDB after first load. Dukascopy V1 datafeed JSONP is DEAD (429/301 since 2026-11-09) — live now uses the Dukascopy json3 endpoint (freeserv.dukascopy.com) instead. TV UDF demo, Binance.com, Twelve/Alpha/OANDA are NOT used (see ANALYSIS.md §3 for the measured reasons).

Speed — preview vs full run

Run previews only the last 20,000 bars so signals appear on the chart quickly (a few seconds for light scripts, up to ~1 min for heavy ones). The compiled Pine script is cached in the worker, so switching preview ↔ full does not recompile. Run full history (1M) runs all 1,008,574 bars (minutes for heavy scripts) and is the only run that produces real Strategy Tester / 8-gate numbers; opening the Strategy Tester tab with only a preview result starts a full run automatically. While a run is in progress, Run doubles as Cancel (terminates the worker) and the status bar shows elapsed time. Full-history numbers are unchanged by the speed work: R7 base variant still gives 2,504 trades, PF 0.688, net −$9,982.83 (parity, see PARITY.md).

Built-in indicators (fx Indicators button, top bar)

No Pine needed: Moving Average, EMA, Bollinger Bands, RSI, MACD, Stochastic, ATR, Supertrend. Overlays draw on the price pane, oscillators get their own pane each (own scale). Click an active indicator's chip (top-left of the chart) or change its numbers in the panel to edit/remove it. Indicators follow timeframe changes and live updates, and are saved in localStorage. Formulas match Pine ta.* (EMA/RMA seeded with the first value, population std for Bollinger). VWAP is not included — the bundled data has no volume (OHLC only). Recomputing all indicators on the full 1M-bar series takes ~0.5s; the wheel zoom itself stays instant because plots are drawn from the visible window only.

Keyboard / mouse

Drag chart to scroll · wheel zooms to the cursor (scroll up = zoom in, scroll down = zoom out, like TradingView; trackpad scrolls are smooth, one flick no longer jumps to 20 or 20,000 bars) · wheel also works over the oscillator pane · double-click to reset view · “Show full history” (⤢) to see all 1M bars downsampled. The last candle always sits 10 bars away from the price axis (right offset, like TradingView) so it is never jammed against the axis — and that space is also what keeps the wheel anchor exact when you zoom out at the newest bar. Toolbar buttons: ＋ zoom in, － zoom out (around the chart centre), ⇥ jump to the newest bar keeping the current zoom, ⌂ reset view. Live updates keep your zoom/pan — they no longer snap back to the last 300 bars.
